# passmgmt

加密资源库（桌面版网页应用）。把文本、照片、文件作为条目集中加密保存成一个 `.vault` 文件；用密码打开、修改，再重新加密导出为新文件。

纯前端，无后端，数据只在内存和你导出的文件里。

必须通过 `http://` 或 `https://` 访问（WebCrypto 只在安全上下文可用），不能直接双击打开 `dist/index.html`。

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm test         # 单元测试
npm run build    # 生产构建，产物在 dist/
```

## 使用

1. **新建**：设置密码，从空库开始。
2. **添加条目**：每个条目有名称、描述，以及若干字段。
3. **字段**：字段名 + 值；值可以是文本，也可以是一个附件（照片、文件）。
4. **搜索**：匹配名称、描述、字段名、文本值、附件文件名。
5. **导出**：把当前内容重新加密，下载为新的 `.vault` 文件。
6. **导入**：选择 `.vault`，输入密码解密。

未导出就关闭页面，修改会丢失；界面会显示"未导出"状态。

## 加密

- 密码 → Argon2id（64 MiB / 3 次 / 1 并行）→ KEK
- KEK 解封随机生成的 DEK（AES-256-GCM 包装）
- DEK 分块加密整个数据体（每块 1 MiB，独立随机 IV）
- 文件头作为 AAD，分块 AAD 绑定块序号和结束标记；篡改、重排、截断都会导致解密失败
- 密码错误或文件损坏：直接失败，不猜测、不修复

**密码丢失 = 数据永久丢失，没有恢复机制。**

## 结构

```
src/crypto/   Argon2id、分块 AES-GCM、密钥包装
src/vault/    数据模型、.vault 头格式、容器打包、创建/打开/导出
src/state/    React 状态与操作
src/ui/       欢迎页、工作区、条目编辑器、字段行
tests/        加密、格式、容器、端到端回归测试
```
